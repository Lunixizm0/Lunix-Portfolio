Independent Securıty Researcher

June 2024 - Present

  • Identified a critical authorization vulnerability (CWE-862) in LiderAhenk: the broker enforces no ACL between agents, allowing any authenticated agent to publish commands to another agent's topic. Because credentials can be obtained from installing ahenk agent, this effectively grants unauthenticated remote command execution across managed endpoints.
  • Methodology: noticed the agent had no client-side authorization checks and hypothesized the broker might not enforce this either; confirmed it by provisioning a second agent with credentials extracted from a standard ETAP VM, then publishing crafted commands to another agent's pulsar topic.
  • Vendor confirmed and remediated; coordinated with CERT-TR; MITRE CVE assignment pending.
